# ¬¬||🧊|| : Cubical Classics

> From program halts in the tale,
> towards program only *Übermensch* is able to run.

`cubical-classics` is an experimental Agda library for doing classical
mathematics in Cubical Agda. It develops classical principles, ordered algebra,
constructive Dedekind reals, classical Dedekind-cut completions,
MacNeille-complete real numbers, and some basic real analysis.

We are open to advice and contributions!

## Highlights

The library proves, among other things:

- choice implies excluded middle, through Cubical's Diaconescu theorem and the
  local `Oracle`;
- SIP/univalence for ordered commutative rings, strictly ordered commutative
  rings, ordered fields, and MacNeille-complete ordered fields;
- canonical ordered homomorphisms from `ℤ` and `ℚ` into ordered targets;
- LEM-free constructive Dedekind reals over `ℚ`, with ordered arithmetic and
  same-universe Dedekind completeness;
- the LEM-based classical Dedekind-cut completion of an Archimedean ordered
  field forms a MacNeille-complete ordered field;
- `ℝ` is the unique MacNeille-complete Archimedean ordered field generated by
  `ℚ`;
- compactness of closed intervals, Heine-Borel, Bolzano-Weierstrass, Cauchy
  completeness of `ℝ`, and the intermediate value theorem.

## Dependencies

This project tracks the current development version of
[the Cubical Agda library](https://github.com/agda/cubical), not the latest
tagged release.

Known working setup:

- Agda 2.8.0
- Cubical Agda library `master`, tested at commit `9216603`

Older Cubical releases, including the `v0.9` checkout, are not expected to
work. The code uses several APIs that are only available on recent `master`.

To type-check the library:

```sh
agda --build-library
```

## Layout

The code is split by whether it uses the library's classical `Oracle`.

- `Constructive/Preliminary/` contains logic and natural-number lemmas that do
  not use classical axioms.
- `Constructive/Algebra/OrderedCommRing/` builds on Cubical's ordered
  commutative rings, with morphisms and univalence.
- `Constructive/Algebra/StrictlyOrderedCommRing/` adds strict orders,
  trichotomy, absolute value, Archimedean structures, morphisms, univalence,
  and the `ℤ` and `ℚ` instances.
- `Constructive/Algebra/OrderedField/` adds ordered fields, field morphisms,
  ordered-field lemmas, the rational ordered field, and the canonical
  inclusion of `ℚ` into any ordered field.
- `Constructive/DedekindReals/` contains the LEM-free constructive Dedekind
  reals over `ℚ`, their cut presentation, ordered arithmetic, and constructive
  Dedekind completeness.
- `Classical/Axioms/` contains the `Oracle` interface, choice, excluded middle,
  Diaconescu's theorem via Cubical, and local propositional resizing.
- `Classical/Foundations/Powerset/` develops impredicative powersets,
  membership, Boolean operations, finiteness, and finite big operations.
- `Classical/Algebra/OrderedField/` contains extrema, MacNeille completeness,
  and completion of Archimedean ordered fields.
- `Classical/DedekindCut/` contains the Oracle-based classical Dedekind-real
  completion by cuts, its algebra and order, the ordered-field instance,
  MacNeille completeness, and the universal property.
- `Classical/Topology/` contains topological spaces, neighbourhoods,
  Hausdorff spaces, compactness, metric spaces, limits, cluster points, and
  Cauchy sequences.
- `Classical/Analysis/Real/` contains the real numbers, real topology, compact
  intervals, Heine-Borel, monotone convergence, Bolzano-Weierstrass, and
  Cauchy completeness.
- `Classical/Analysis/Function/` contains continuous partial functions on
  subsets of `ℝ` and the intermediate value theorem.
- `Solvers/` contains small Boolean, propositional, classical, and powerset
  solvers used by the powerset development.
